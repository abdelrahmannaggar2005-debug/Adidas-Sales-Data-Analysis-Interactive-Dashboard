## 📂 Dataset Description

The dataset contains records of Adidas sales transactions with key fields such as:

- `Invoice Date` — date of the sale
- `Region`, `City`, `State` — geographic attributes
- `Retailer` / `Retailer ID` — sales channel or store
- `Product` — item sold
- `Units Sold`, `Total Sales` — core transactional metrics
- `Operating Profit` / `Profit Margin` — financial results

These enable comprehensive analysis of trends, regional shifts, retailer performance, and profitability dynamics. :contentReference[oaicite:2]{index=2}

## 🧹 Data Preparation

Before visualization, the dataset was:

1. Loaded and inspected for consistency (dates, formatting, nulls).
2. Transformed in Power Query:   
   - Standardized date and text formats  
   - Extracted time features (Year, Month)  
   - Created calculated columns (e.g., Profit Margin, Unit Revenue)
3. Ensured clean aggregations and eliminated duplicates or missing values.

These steps ensure accurate and consistent results in the dashboard.
